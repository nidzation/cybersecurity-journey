# 1.1 Laptop Hardware - Professor Messer (CompTIA A+ 220-1201)

## Overview
Laptops are compact, highly integrated devices. This makes them powerful for mobile use but more difficult and precise to troubleshoot and repair compared to desktops. Repairability varies significantly between manufacturers and models.

## Key Topics & Notes

### Batteries
- **Common types**: Lithium-Ion (Li-ion) and Lithium-Ion Polymer (Li-Po)
  - No "memory effect" → can charge at any time
- **Form factors**: Manufacturer-specific — must match exact model
- **Replacement**:
  - **Modular**: Easy, user-replaceable (often with a latch/button)
  - **Built-in**: Requires full disassembly by technician

### Keyboards
- Most frequently replaced component
- Usually connected via **ribbon cable** to the system board
- **Troubleshooting tip**: Plug in an external USB keyboard to isolate the issue (hardware vs OS)
- **Keycap replacement**: Very delicate on laptops — follow manufacturer instructions carefully
- Often include Fn key + special functions and sometimes a numeric keypad

### Memory (RAM)
- Uses **SO-DIMM** (Small Outline Dual In-line Memory Module) — smaller than desktop DIMMs
- Some laptops: Modular (easy access via bottom panel)
- Others: Soldered to motherboard → requires full system board replacement for upgrades

### Storage
- **Older**: 2.5" HDD (spinning platters)
- **Modern**: SSD (Solid State Drive) — faster, more reliable, no moving parts
  - Form factors: 2.5" or **M.2** (much smaller, common in newer laptops)
- **M.2 advantages**: Single screw installation, very small footprint
- **Drive cloning/imaging**: Recommended when upgrading HDD → SSD
  - Use manufacturer-provided software or third-party tools (e.g., Acronis, Macrium Reflect)

### Wireless Connectivity
- **Wi-Fi (802.11)**: Often via Mini-PCIe or M.2 cards (modular in older laptops)
- **Bluetooth**: PAN (Personal Area Network) — for mice, keyboards, etc.
- **Antennas**: Usually two (Main + Auxiliary) for Wi-Fi + sometimes one for Bluetooth. Wires run through the display hinge.

### Biometrics
- **Windows Hello**: Face recognition + Fingerprint reader
- Hardware: Built-in webcam (Face) or fingerprint scanner
- Significantly improves security over passwords

### NFC (Near Field Communication)
- Very short range (~4 cm or less)
- Used for contactless payments, access cards, authentication in hospitals/warehouses

### Camera & Microphone
- Built-in webcam at top of display + dual mics
- Good for video calls
- Option to add external webcam for better quality

## Key Takeaways
- Modularity varies greatly by manufacturer/model
- Always check service manuals before disassembly
- Upgrading storage (HDD → SSD) gives the biggest performance boost
- SO-DIMM, M.2, and ribbon cables are common laptop-specific components
