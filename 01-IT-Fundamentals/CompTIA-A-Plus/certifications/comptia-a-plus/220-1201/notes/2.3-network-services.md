## Core Network Services

### DNS (Domain Name System)
- Converts fully qualified domain names (e.g., professormesser.com) ↔ IP addresses
- Also supports reverse lookups
- Highly distributed system (thousands of servers worldwide)
- Critical service – almost everything relies on it

### DHCP (Dynamic Host Configuration Protocol)
- Automatically assigns IP address, subnet mask, default gateway, DNS servers
- Makes network configuration seamless for end users
- Enterprise environments usually have multiple DHCP servers for redundancy
- Can also reserve specific IPs for printers, servers, etc.

### File Sharing
- Centralized storage of documents and files
- Common protocols:
  - **SMB** (Server Message Block) → Windows
  - **AFP** (Apple Filing Protocol) → macOS
- Users usually just see a shared folder (protocol is hidden)

### Print Services
- Manages print jobs (queuing, ordering, delivery)
- Can run on a dedicated print server or directly on the printer
- Common protocols: SMB, IPP (Internet Printing Protocol), LPD

### Email Servers
- Handle sending and receiving of email
- Extremely high uptime expectation
- Can be cloud-based or on-premises

### Syslog + SIEM
- **Syslog**: Protocol used to send log messages from devices
- **SIEM** (Security Information and Event Manager): Central place that collects and correlates all logs
- Essential for troubleshooting and security monitoring

### Web Servers
- Respond to HTTP / HTTPS requests from browsers
- Store and serve HTML pages and web applications

### Authentication Server (AAA)
- **AAA** = Authentication, Authorization, Accounting
- Central database of users and credentials
- Critical in enterprise environments (usually redundant)
- Home networks rarely use a dedicated authentication server

### Database Servers
- Store structured data in tables (relational databases)
- Common language: **SQL** (Structured Query Language)
- Examples: Microsoft SQL Server, MySQL, PostgreSQL, etc.

### NTP (Network Time Protocol)
- Keeps the date and time accurate on all devices
- Extremely important for:
  - Log correlation
  - Encryption / certificates
  - Authentication
- Devices periodically check an NTP server

### Spam Gateway
- Filters incoming email and separates spam from legitimate messages
- Can be cloud-based or on-premises
- Not 100% accurate (sometimes legitimate mail ends up in spam)

## Security & Advanced Services

### All-in-One Security Appliance / UTM / NGFW
Also called:
- Unified Threat Management (UTM)
- Next-Generation Firewall (NGFW)
- Web Security Gateway

Common features:
- Firewall
- URL / content filtering
- Malware scanning
- Spam filtering
- Intrusion Prevention (IPS)
- VPN
- Bandwidth shaping
- Router / switch functions

### Load Balancer
- Distributes traffic across multiple servers
- Improves performance and availability
- Automatically removes failed servers from the pool
- End users don’t notice when a server fails

### Proxy Server
- Acts as a middleman between client and server
- Client → Proxy → Internet → Proxy → Client
- Benefits:
  - Security scanning
  - Content filtering
  - Caching
  - Access control
- Can be almost invisible to the user

## Specialized Systems

### SCADA / ICS
- **SCADA** = Supervisory Control and Data Acquisition
- **ICS** = Industrial Control System
- Used in power plants, oil & gas, manufacturing, etc.
- Allows remote monitoring and control of industrial equipment
- Almost always placed on a highly segmented and secured network

### Legacy Systems
- Older systems that are still running (sometimes 10–20+ years old)
- Still important → often the reason they haven’t been replaced
- Require special knowledge to maintain

### Embedded Systems
- Purpose-built devices (fire alarms, time clocks, etc.)
- Operating system is usually not directly accessible
- Managed through manufacturer tools
- Low maintenance once installed

### IoT (Internet of Things)
- Broad category: smart appliances, thermostats, speakers, doorbells, etc.
- Security is often weak
- Best practice: place IoT devices on a **separate segmented network**

---

## Key Takeaways
- Many services work together to keep a network functional
- Critical services (DNS, DHCP, Authentication, Email, NTP) should have redundancy
- Security appliances and load balancers improve both security and availability
- Specialized systems (SCADA, IoT, Embedded) need extra network isolation
- Understanding what each service does is essential for troubleshooting
