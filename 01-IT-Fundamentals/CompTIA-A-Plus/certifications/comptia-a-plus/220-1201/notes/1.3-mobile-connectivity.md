## Overview
This section focuses on how mobile devices connect to cellular networks, Wi-Fi, Bluetooth, and location services.

## Cellular Networks
- **Cell Towers**: Land is divided into "cells" with antennas using different frequencies
- **Generations**:
  - **3G** (1998): Enabled data services (GPS, video, mobile TV)
  - **4G / LTE**: Up to 150 Mbps (GSM-based, EDGE)
  - **LTE Advanced (LTE-A)**: Up to 300 Mbps
  - **5G** (2020+): Up to 10 Gbps (high frequencies) or 100–900 Mbps
    - Huge boost for IoT devices, cloud processing, real-time data

- **Airplane Mode**: Disables all radios (cellular, Wi-Fi, Bluetooth). You can re-enable specific ones.

## Wi-Fi (802.11)
- High-speed wireless networking (home/office)
- Limited range — connects via access points
- Supports voice, video, and data
- **Wi-Fi Calling**: Use Wi-Fi for calls when cellular signal is weak

## Hotspot / Tethering
- **Hotspot**: Phone acts as Wi-Fi router (multiple devices connect)
- **Tethering**: Share internet with one device (USB/Bluetooth)
- Requires carrier support (may have extra fees)

## SIM / eSIM
- **SIM (Subscriber Identity Module)**:
  - Physical card with carrier info, phone number, contacts, messages
  - Allows easy swapping between phones
- **eSIM (embedded SIM)**:
  - Built into the device (not removable)
  - Can be transferred digitally (QR code or software)
  - Supports multiple SIM profiles on one device

## Bluetooth Pairing
- Creates a secure, trusted connection
- Process:
  1. Enable Bluetooth on both devices
  2. Make devices discoverable
  3. Select device and confirm **PIN** (may be fixed or dynamic)
  4. Once paired, devices reconnect automatically
- Used for headsets, speakers, keyboards, etc.

## GPS & Location Services
- **GPS (Global Positioning System)**:
  - Created by US Department of Defense
  - Uses satellites (needs 4+ for accurate fix)
  - Provides latitude, longitude, altitude
- **Assisted Location**:
  - Wi-Fi positioning (nearby networks)
  - Cellular tower triangulation
- Useful when GPS signal is poor (indoors, urban canyons)

## Key Takeaways
- Cellular technology has evolved dramatically from 3G → 5G
- SIM/eSIM enables easy carrier/device switching
- Multiple connectivity options (cellular, Wi-Fi, Bluetooth) provide redundancy
- GPS + assisted location gives reliable positioning

## Mobile Device Management (MDM)

### Overview
MDM solutions allow central management of company and personal mobile devices.

### Device Ownership Models
- **BYOD (Bring Your Own Device)**:
  - Employee owns the phone
  - Company manages work data only
  - Requires clear separation of personal vs corporate data
- **COPE (Corporate Owned, Personally Enabled)**:
  - Company buys and owns the device
  - Assigned to employee for work + personal use
  - Full company control
- **CYOD (Choose Your Own Device)**:
  - Employee chooses from approved devices
  - Company purchases and manages

### MDM Capabilities
- Set policies: App allow/deny lists, camera/GPS restrictions, screen lock requirements
- **Containerization**: Separate work profile from personal data
- Security: Enforce screen locks, PINs, multi-factor authentication (MFA/2FA)
- Remote management: Push configurations, apps, email settings
- Data protection: Backup, remote wipe (especially important if device is lost)
- Monitoring: Device inventory (IMEI, OS version, user info)

### Key MDM Features
- **Central Console**: View all devices, drill down into details
- **Restrictions**: Disable camera, FaceTime, Siri, printing, etc.
- **Synchronization (Over-the-Air)**:
  - Control what data syncs (email, contacts, calendar, etc.)
  - Choose Wi-Fi only vs cellular
  - Set limits on automatic downloads
- **Application Management**: Push approved apps, block others

### Real-World Benefits
- Consistent security policies across all devices
- Easy onboarding (email, apps, settings pushed automatically)
- Better data protection and recovery options
- Reduced administrative overhead
